# HandMax Frontend (Ionic + Angular)

Interface web da plataforma HandMax, desenvolvida para apoiar uma escolinha de handebol sem fins lucrativos. O sistema visa promover inclusão social, saúde e educação por meio do esporte, oferecendo ferramentas digitais para gestão de alunos, treinos e eventos.

## 🌟 Propósito do Projeto

HandMax é uma iniciativa comunitária que busca:

- Organizar e facilitar o trabalho de treinadores e voluntários  
- Acompanhar o desenvolvimento dos alunos  
- Promover o esporte como ferramenta de transformação social  

## 🧰 Tecnologias Utilizadas

- **Ionic Framework** – Interface híbrida e responsiva  
- **Angular** – Framework para construção de aplicações web  
- **TypeScript** – Tipagem estática para maior segurança  
- **SCSS / CSS** – Estilização modular e escalável  
- **RxJS** – Programação reativa  
- **Angular Router** – Navegação entre páginas

```
frontend/
├── src/

│   ├── assets/         # Imagens e ícones
│   ├── environments/   # Configurações de ambiente

└── README.md           # Este documento
```

## 🚀 Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   ionic serve
   ```

3. Acesse no navegador:
   ```
   http://localhost:8100
   ```

> Certifique-se de que o backend esteja rodando para que a comunicação com a API funcione corretamente.

## 📌 Funcionalidades

- Cadastro e gerenciamento de alunos  
- Registro de presença e desempenho  
- Agendamento de treinos e eventos  
- Painel administrativo para treinadores  
- Interface adaptada para dispositivos móveis  

## 🛠️ Requisitos

- Node.js 18+  
- NPM ou Yarn  
- Ionic CLI  
- Backend HandMax em execução
